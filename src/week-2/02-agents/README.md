# Instrukcje dla agentów AI

Plik `AGENTS.md` definiuje zasady pracy agenta AI w tym module: rolę mentora, styl komunikacji i sposób tłumaczenia zagadnień programistycznych.
To centralne miejsce, które standaryzuje odpowiedzi tak, aby wspierały naukę poprzez intuicję, praktyczne przykłady i aktywne sprawdzanie zrozumienia.
